== Scenario B: identical code and data, different concurrency ==

concurrency           p50          p95          p99     throughput

200                  1 ms       134 ms       142 ms     7510 req/s

Throughput stops climbing once concurrency passes the pool size: the pool,
not the code, is the ceiling. Note WHERE the pain shows up -- the median
barely moves while the tail explodes, because an unfair semaphore lets some
waiters be overtaken repeatedly. A dashboard showing average latency would
report this system as healthy.
