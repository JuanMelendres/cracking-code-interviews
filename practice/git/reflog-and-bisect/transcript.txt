- `git reset --hard`, `git rebase`, and `git commit --amend` never delete an
  object outright -- they move refs (branch pointers) and leave the old
  objects reachable only via the reflog (a local, per-repo, time-limited log

  unreachable entries) until `git gc` eventually prunes genuinely unreferenced
  objects.

  commit out of 5 -- ceil(log2(5)) = 3 in the worst case, 2 here because the
