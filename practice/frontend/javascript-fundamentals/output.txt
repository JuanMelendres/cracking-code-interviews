--- WHY setTimeout(fn, 0) DOES NOT RUN IMMEDIATELY ---
The call stack must fully empty, THEN the microtask queue must fully
drain, and only THEN does the event loop pull the next macrotask off
the timer queue. Expected order printed above: 1, 2, 3, 4, 5.

=== src/equality.js ===
--- DEMO: == vs === surprises ---
[] == false          -> true
[] === false         -> false
'0' == false         -> true
'0' === false        -> false
null == undefined    -> true
null === undefined   -> false
'' == 0              -> true
'' === 0             -> false
[] == ''             -> true
[1] == 1             -> true
'1' == 1             -> true
'1' === 1            -> false

--- WHY: == coerces types before comparing, === never does ---
[] == false  coerces both sides toward numbers: [] -> "" -> 0, false -> 0, so 0 == 0 is true.
'0' == false coerces false -> 0 and '0' -> 0, so 0 == 0 is true, even though '0' is a truthy string.
=== skips coercion entirely and compares type + value directly, which is why this repository
always recommends === (and !==): it removes an entire class of "why is this true?!" bugs.
