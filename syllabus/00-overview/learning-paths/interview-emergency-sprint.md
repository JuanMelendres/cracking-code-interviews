# Learning Path: Interview Emergency Sprint

**Audience:** an engineer with ≤8 weeks until a known interview loop, who needs a structured, IWI-ranked, time-boxed compression of the full programme — not a leisurely first pass and not a pure refresh of material already known.

**Goal:** cover the highest-interview-weight topics across every domain, in priority order, within a fixed clock.

**Time budget:** ≤8 weeks, structured week by week.

**Stops at:** L3 for most topics, selectively L4 where a specific target loop is known to probe it (a named Staff-level round, for instance).

## This path is not new material — it is `study-packs/`, referenced wholesale

Per the transformation plan's own §6, this path is deliberately **not** a new document duplicating existing content. `study-packs/` already is this path: a real, existing 6-week (extendable), IWI-ranked, feedback-driven sprint, built and refined across this project's entire history — rebuilding it here as a second "emergency sprint" document would be exactly the duplication this project's canonical-ownership rule exists to prevent.

**Start here:** [`study-packs/week-01/README.md`](../../../study-packs/week-01/README.md), and proceed week by week through the numbered `study-packs/week-NN/` directories in order. Each week's own `README.md` states that week's outcome, required reading (with links to the canonical `syllabus/` chapters this transformation moved), hands-on exercises, and a retrospective — the same structure this plan's own Study Pack Standard defines.

## Why this path exists as a named entry at all

Even though it adds no new content, naming it here matters for navigation: a reader arriving at `syllabus/00-overview/` looking for "I have very little time" should find a clear pointer to the right existing resource, rather than assuming `study-packs/` is a separate, older system unrelated to the new domain structure. It is not — every study-pack week already references the canonical `syllabus/` chapters this transformation produced, cross-linked in both directions.

## If more time is actually available

Consider [Mid → Senior](mid-to-senior.md) or [Senior → Staff](senior-to-staff.md) instead — both cover comparable ground with more room to build depth rather than compress it, and neither is bound to a specific 6–8 week clock.
