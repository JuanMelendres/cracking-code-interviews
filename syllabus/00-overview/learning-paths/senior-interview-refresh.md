# Learning Path: Senior Interview Refresh

**Audience:** an experienced engineer with an upcoming interview loop, who already has the depth — this path is recall practice, not new learning.

**Goal:** rapid, high-confidence recall of material already known, plus a final pass on delivery mechanics.

**Time budget:** 3–5 focused days, or one lighter week if spread out.

**Stops at:** L3, review only. This path deliberately does not introduce new L4 material — that's what [Senior → Staff](senior-to-staff.md) is for, on a normal (non-emergency) timeline.

Per the [Mastery Model](../mastery-model.md)'s own rule, "read this chapter" is never a valid criterion — every day below ends with an explain-it-cold or compare-it check, not just re-reading.

## The review rotation

This path is deliberately not an enumerated topic list — re-listing every topic here would duplicate the cheat-sheet and flashcard layers that already exist specifically for this purpose (see this project's own duplication rule). Instead:

1. **Daily domain sweep.** Pick 2–3 domains per day from [`cheat-sheets/`](../../../cheat-sheets/README.md) (163 entries, one page per topic, optimized for exactly this kind of rapid review) and read every cheat sheet in that domain start to finish.
2. **Spaced-repetition pass.** Run through [`flashcards/`](../../../flashcards/README.md) for the same domains, same day — the cheat sheet refreshes the model, the flashcards test whether it actually stuck.
3. **One explain-it-cold check per domain, out loud.** Pick one topic covered that day, open its canonical chapter's own "Interview Questions" section (every chapter has one, per the [Topic Specification](../topic-specification.md)'s 20-section template), and answer it aloud, unscripted, timed to its stated length (30-second / 2-minute / deep-dive) — this is the "not just reading" check the Mastery Model requires.

## Completion criteria

- Every domain likely to appear in the upcoming loop has had at least one cheat-sheet + flashcard pass this week.
- The six delivery-mechanics chapters above have been re-read in the last 3 days before the loop, not just at some earlier point in preparation.
- At least one full mock interview has been run against [`practice/mock-interviews/`](../../../practice/mock-interviews/README.md) since starting this refresh.

## If time is genuinely short

See [Interview Emergency Sprint](interview-emergency-sprint.md) instead — a structured ≤8-week compression of the full programme, not a pure refresh.
