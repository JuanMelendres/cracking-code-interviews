# Java

The primary specialization and deepest track: language core, collections, JVM internals, and concurrency. All 49 chapters have physically relocated here across four subdomains, and — as of 2026-09-04 — all 49 now carry the full L1–L4 mastery ladder. (`benchmarking-and-jmh-pitfalls.md`, previously in `handbook/jvm/`, belongs to `16-performance-jvm` instead and was not moved here — it awaits that domain's own Phase 3 turn.)

> **Phase 3 update (2026-09-03).** This domain's full existing content has physically relocated via `git mv` from `handbook/{java-core,collections,jvm,concurrency}/`, preserving file history. 235 files across the rest of the repository (`cheat-sheets/`, `flashcards/`, `production-cookbook/`, other `handbook/` chapters, `study-packs/`, `architecture-atlas/`, `practice/`) had their cross-references to these 49 chapters updated to the new paths; a full repository-wide link-resolution pass confirms zero references broken by this move. See the repository-root `CHANGELOG.md` for the full account, including a discovered class of pre-existing, unrelated broken links (in `behavioral-handbook/`, `AGENTS.md`/`CLAUDE.md`, and `production-cookbook/`) that predate this migration and were not introduced by it.
>
> **Phase 5 update (2026-09-04) — domain complete.** All four subdomains — `collections` (T-201–T-209, 9 chapters), `language-core` (T-101–T-115, 15 chapters), `jvm-internals` (12 chapters), and `concurrency` (13 chapters) — have now received the plan's own additive L1/L2 retrofit (§2.4): every chapter gained a new "Level 1 — Foundation" and "Level 2 — Working Knowledge" section, inserted between the existing "Why This Matters in Interviews" and "Mental Model" sections, per the plan's own stated placement. No existing sentence was deleted, reworded, or moved anywhere across all 49 chapters — every retrofit was a pure insertion, verified by diff, file by file. Each chapter also gained a `mastery_levels_covered: [L1, L2, L3, L4]` front-matter field, and a `topic_id` field where one already exists in the Master Topic Register (5 `jvm-internals` chapters have none, and were left without a fabricated one). **`02-java` is the first fully L1–L4 domain in the syllabus.**
>
> **Junior Fundamentals gap found and started (2026-09-07).** The L1/L2 retrofit above added *intuition* for existing Senior-level topics — it never added a true zero-to-one entry point, because this domain's original Target Audience (per `CLAUDE.md`) assumed 5+ years of Java experience already. An audit triggered by the user (checking whether OOP itself was covered before selling this repository as Junior-through-Staff) found it was covered only narrowly — [T-102, Polymorphism and Dynamic Dispatch Mechanics](language-core/polymorphism-and-dynamic-dispatch.md), by original design, scopes "OOP" down to the one Senior-differentiating mechanic, not the four pillars — and the same narrow-assumption pattern repeats across `05-spring`, `06-databases`, `07-api-design`, and `08-testing`. The user chose the full-scope fix: one true "101" chapter per affected domain, using a newly reserved ID range (`T-2200`–`T-2299`, see `00-project/syllabus-transformation-plan.md`). [Java OOP Fundamentals: Classes, Objects, and Interfaces](language-core/java-oop-fundamentals-classes-objects-and-interfaces.md) (T-2201) is the first of five, with 3 real, compiled, executed demos (19/19 assertions passing on OpenJDK 21.0.12) proving encapsulation, the interface-vs-abstract-class distinction, and composition-over-inheritance directly rather than asserting them. **Update: all five chapters (T-2201–T-2205) are now written** — see `syllabus/07-api-design/INDEX.md`'s matching note for the closing entry. Cheat sheet and flashcard deck for T-2201 added 2026-09-07 (`cheat-sheets/README.md`, `flashcards/README.md`).
>
> **Two further gaps found and closed (2026-09-08).** After completing the Junior Fundamentals initiative, the user asked directly whether the repository now genuinely served a low-to-high-seniority reader. Honest answer: not entirely — T-2201 itself assumed the reader could already read an `if` statement and a `for` loop (true programming-syntax literacy was never taught anywhere in this repository), and the domain jumped from "here's a class" straight to `HashMap`/`ArrayList` internals with no "what is a List/Map/Set and when do you use each" usage-level stop in between. Closed both: [Java Syntax Fundamentals: Variables, Control Flow, and Methods](language-core/java-syntax-fundamentals-variables-control-flow-and-methods.md) (T-2206) is now the true first stop (T-2201's own `prerequisites:` updated to point to it), and [Collections Usage Fundamentals: List, Map, and Set](collections/java-collections-usage-fundamentals-list-map-and-set.md) (T-2207) sits between OOP Fundamentals and this domain's internals-focused collections chapters. Both ship with real, compiled, executed demos (9/9 and 14/14 assertions passing respectively, OpenJDK 21.0.12) — **`02-java` now has 52 chapters.**
