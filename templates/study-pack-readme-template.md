# Study Pack README Template

A study pack is a guided weekly learning experience, not a duplicate handbook. Individual study files should focus on one learning objective, reference canonical handbook chapters, include exercises and answer drills, and avoid reproducing full handbook explanations.

```markdown
---
title: Week NN — <Theme>
document_type: study-pack
week: NN
status: draft
estimated_hours: <number>
---

# Week NN — <Theme>

## Prerequisites
```
