# Flashcard Template

Prefer one concept per card. Avoid cards that require memorizing long paragraphs. Use `## Card:` inside a standalone `flashcards/*.md` file (no parent `## Flashcards` heading in that file); use `### Card:` when nested under a chapter's own `## Flashcards` section.

```markdown
## Card: <Short title>

**Prompt:**
<Question>

**Answer:**
<Concise answer>

**Why it matters:**
<Interview relevance>

**Common trap:**
<Mistake>

**Related:**
<Relative links>
```
