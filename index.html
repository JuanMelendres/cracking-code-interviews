    Cracking Code Interviews¶

    Structured interview preparation for Java backend engineers across the full Junior-through-Staff ladder, plus a parallel React/Next.js frontend track — start at true fundamentals with no prior experience assumed, or start wherever you already are and go deeper toward Senior or Staff.

    Where to start¶

    • New to backend, 0–2 years

      No prior Java/SQL/Spring assumed.

      Junior → Mid

    • Working engineer, 2–5 years

      Ships features, needs Senior-level internals depth.

      Mid → Senior

    • Senior, aiming at Staff

      Systemic/organizational judgment a Staff loop tests.

      Senior → Staff

    • Deep Java-stack focus

      Java, Spring, DB, messaging, JVM — depth over breadth.

      Backend Java Specialization

    • Senior/Staff, refreshing

      Depth already in place, interview coming up — recall, not new learning.

      Senior Interview Refresh

    • New to frontend, 0–2 years

      No prior JS/TS/React assumed.

      Frontend Junior → Mid

    • Frontend/full-stack, working

      Needs Senior-level React/Next.js internals depth.

      Frontend Mid → Senior

    • Urgent timeline

      Highest-impact material fast, regardless of level.

      Interview Emergency Sprint

    • Looking something up

      22 domains, every topic Foundation through Staff depth.

      Syllabus

    • Cramming, interview soon

      Rapid review, no full chapters.

      Cheat sheets · Flashcards

    See Study Packs for the full picture of how these eight programs relate.

    What's here¶

    • Syllabus

      The canonical technical reference — 22 domains, one chapter per topic, each teaching Foundation through Staff depth in a single place.

    • Study Packs

      Week-by-week schedules across 8 programs (5 backend, 2 frontend, 1 emergency-timeline).

    • Cheat Sheets

      One-page rapid review per topic.

    • Flashcards

      Spaced-repetition decks per topic.

    • Architecture Atlas

      Full system-design write-ups with diagrams and trade-offs.

    • Production Cookbook

      Real, diagnosed incident write-ups in postmortem format.

    Every technical claim in this material is backed by real, executed code or a real, cited official source — never invented statistics or untested code presented as working.

    Looking for something specific?¶

    The search bar (top of every page) indexes every chapter, cheat sheet, and flashcard by real technical terms — @Transactional, CAP theorem, N+1, CSRF, a class name — not just chapter titles. Faster than browsing if you already know what you're looking for.
