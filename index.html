    Cracking Code Interviews¶

    Structured interview preparation for Java backend engineers across the full Junior-through-Staff ladder, plus a parallel React/Next.js frontend track — start at true fundamentals with no prior experience assumed, or start wherever you already are and go deeper toward Senior or Staff.

    Where to start¶

    • New to backend development? Start with the Junior → Mid study pack.
    • Shipping features, want Senior depth? Go to Mid → Senior.
    • Senior, aiming for Staff? Go to Senior → Staff.
    • Just want to look something up? Browse the Syllabus — 22 domains, every topic taught from Foundation through Staff depth in one place.
    • Cramming for an interview soon? Cheat sheets and flashcards.

    What's here¶

    Section What it is
    Syllabus The canonical technical reference — 22 domains, one chapter per topic, each teaching Foundation through Staff depth in a single place
    Study Packs Week-by-week schedules across 8 programs (5 backend, 2 frontend, 1 emergency-timeline)
    Cheat Sheets One-page rapid review per topic
    Flashcards Spaced-repetition decks per topic
    Architecture Atlas Full system-design write-ups with diagrams and trade-offs
    Production Cookbook Real, diagnosed incident write-ups in postmortem format

    Every technical claim in this material is backed by real, executed code or a real, cited official source — never invented statistics or untested code presented as working.
