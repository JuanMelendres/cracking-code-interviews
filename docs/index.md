# Cracking Code Interviews

Structured interview preparation for Java backend engineers across the full
**Junior-through-Staff** ladder, plus a parallel React/Next.js frontend track —
start at true fundamentals with no prior experience assumed, or start wherever
you already are and go deeper toward Senior or Staff.

## Looking for something specific?

The search bar (top of every page) indexes every chapter, cheat sheet, and
flashcard by real technical terms — `@Transactional`, `CAP theorem`,
`N+1`, `CSRF`, a class name — not just chapter titles. Faster than browsing
if you already know what you're looking for.
