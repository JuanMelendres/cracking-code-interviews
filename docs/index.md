# Cracking Code Interviews

Structured interview preparation for Java backend engineers across the full
**Junior-through-Staff** ladder, plus a parallel React/Next.js frontend track —
start at true fundamentals with no prior experience assumed, or start wherever
you already are and go deeper toward Senior or Staff.

## Where to start

- **New to backend development?** Start with the [Junior → Mid study pack](study-packs/junior-to-mid/README.md).
- **Shipping features, want Senior depth?** Go to [Mid → Senior](study-packs/mid-to-senior/README.md).
- **Senior, aiming for Staff?** Go to [Senior → Staff](study-packs/senior-to-staff/README.md).
- **Just want to look something up?** Browse the [Syllabus](syllabus/00-overview/INDEX.md) — 21 domains, every topic taught from Foundation through Staff depth in one place.
- **Cramming for an interview soon?** [Cheat sheets](cheat-sheets/README.md) and [flashcards](flashcards/README.md).
